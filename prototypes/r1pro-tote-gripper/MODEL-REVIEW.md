# 箱体与夹具视频对比记录

本记录以仓库根目录的 video-contact-sheet.jpg 和原始视频为当前几何依据。
视频没有完整标定尺度，因此尺寸仍需真机测量；但接触拓扑已经确认，不能再按
“凹槽中另有横条”的旧理解建模。

## 已确认的箱体接口

- 蓝色周转箱两侧各有一个由塑料壁板自身形成的水平凹槽；
- 凹槽是下钩的进入空间，没有独立承力条、黑色横梁或中央安装块；
- 下钩从箱外低位水平进入槽内，完整钩脚越过槽口后短距离向上就位；
- 就位后钩脚上表面贴合凹槽上沿内侧，上夹片同时压住箱沿；
- 左右夹具分别使用左右两个镜像凹槽，共同抬升箱体。

当前Scene Package只生成外壁上段、开放凹槽和外壁下段。下钩从外侧进入，
钩脚上表面向上贴合槽沿内侧。凹槽背板只限定最大插入深度，不是抓取接触目标。
22 mm钩脚进入26 mm凹槽时，钩脚中心插入13 mm，内端与背板保留2 mm净空。

## 已确认的夹具动作

参考视频中的末端是紧凑C形工具，而不是普通平行夹爪：

1. 非工作臂保持身体前方的自然待机位；
2. 工作侧工具在槽口下方接近；
3. 完整下钩水平进入凹槽；
4. 工具短距离向上seat，使钩脚贴合凹槽上沿内侧；
5. 上夹片闭合并压住箱沿；
6. 小幅水平受载时箱体必须跟随工具，才能继续外拉或双侧抬升。

首侧接合不能只以“出现一次接触”为成功。外拉后若箱体没有沿计划方向产生
真实位移，说明钩脚可能只擦碰槽口，Robot Skill必须hold，不能继续让第二侧接合。

## 固定夹具与箱体族

- r1pro-dual-tote-hook-clamp-v1 只有一套固定几何和控制行程；
- 左右末端只做镜像安装；
- 两种箱体共享凹槽顶部到箱沿的86 mm名义接口跨度，容差为±2 mm；
- 生成器校验凹槽宽度、深度和钩脚背板净空，不兼容时直接报错。

## 尚需实测的尺寸

- 左右凹槽的精确宽度、高度、深度和圆角；
- 凹槽上沿内侧到箱沿上表面的距离；
- 箱体材料、空载/满载质量及允许变形；
- 上夹片接触面积、有效行程和额定夹紧力；
- R1 Pro腕部法兰和工具安装变换。

## 评审与验证顺序

1. 运行 authoring/generate_models.py；
2. 运行 authoring/preview_mujoco.py，核对钩脚是否进入左右凹槽；
3. 运行 authoring/verify_mujoco.py，验证低位插入、seat、夹紧、真实抬升和hold；
4. 再进入R1 Pro整机IK、路径规划和Robot Skill物理Gate。
